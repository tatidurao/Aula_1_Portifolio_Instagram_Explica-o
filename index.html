Como usar fontes do Google e ícones no seu site

Nesta aula, vamos aprender como deixar uma página mais bonita usando fontes externas e ícones prontos. A ideia é simples: o aluno vai entender onde colocar os links, como usar no código e onde buscar novas opções.

Antes de começar

Quando criamos uma página em HTML, podemos usar apenas os recursos básicos do navegador. Mas também podemos trazer recursos de fora, como fontes e ícones.

Google Fonts serve para escolher fontes diferentes para o site.
Font Awesome serve para colocar ícones prontos, como coração, estrela, lua, jogo, código e muitos outros.

Esses recursos são chamados dentro da tag <head>, que é a área de configurações da página.

Onde colocar os links?

Os links devem ficar dentro do <head>, antes do nosso arquivo CSS. Isso ajuda o navegador a carregar primeiro os recursos externos e depois aplicar o nosso estilo.

<head> <meta charset="UTF-8"> <title>Meu Portfólio</title> <!-- Fonte do Google --> <link href="https://fonts.googleapis.com/css2?family=Poppins:wght@300;400;500;600;700&display=swap" rel="stylesheet"> <!-- Ícones do Font Awesome --> <link rel="stylesheet" href="https://cdnjs.cloudflare.com/ajax/libs/font-awesome/6.5.0/css/all.min.css"> <!-- Meu arquivo CSS --> <link rel="stylesheet" href="style.css"> </head>

Pense no <head> como a mochila do site. Antes de começar a aula, ele já precisa estar com os materiais certos.

Como usar uma fonte do Google Fonts

Para escolher uma fonte, acesse: fonts.google.com

Lá você pode pesquisar fontes como Poppins, Roboto, Montserrat, Lato, Nunito ou Open Sans. Depois de escolher, o Google Fonts mostra o link que deve ser colocado no HTML.

1

Acesse o Google Fonts

Entre no site e procure uma fonte que combine com o projeto.

2

Copie o link da fonte

O link deve ser colado dentro da tag <head> do HTML.

3

Use a fonte no CSS

Depois, aplique a fonte usando a propriedade font-family.

body { font-family: 'Poppins', sans-serif; }

A parte 'Poppins' é a fonte escolhida. A parte sans-serif é uma fonte reserva, caso a primeira não carregue. É o famoso “plano B”, porque até o navegador gosta de se prevenir.

O que são os números da fonte?

No link da fonte, podem aparecer números como 300, 400, 500, 600 e 700. Eles representam o peso da letra.

family=Poppins:wght@300;400;500;600;700

300 = fonte mais fina
400 = fonte normal
500 = fonte média
600 = seminegrito
700 = negrito

h1 { font-weight: 700; } p { font-weight: 400; }

Como usar ícones com Font Awesome

Para buscar ícones, acesse: fontawesome.com/search

O Font Awesome é uma biblioteca de ícones. Depois que colocamos o link no HTML, podemos usar os ícones com a tag <i>.

<i class="fa-solid fa-heart"></i>

Esse exemplo mostra um coração. O nome do ícone fica dentro da classe.

Coração fa-heart
Código fa-code
Jogo fa-gamepad
Estrela fa-star
Lua fa-moon
Astronauta fa-user-astronaut

Como mudar cor e tamanho dos ícones

Os ícones funcionam quase como textos. Por isso, podemos mudar a cor com color e o tamanho com font-size.

.logo i { color: #ff6b8b; font-size: 28px; }

Também é possível colocar espaço entre o ícone e o texto usando margin-right.

p i { margin-right: 8px; }

Atividade prática

Agora é a vez do aluno personalizar o próprio projeto.

  • Escolha uma fonte no Google Fonts.
  • Copie o link da fonte e coloque dentro do <head>.
  • Aplique a fonte no CSS usando font-family.
  • Acesse o Font Awesome e escolha três ícones.
  • Coloque um ícone no título, um na bio e outro em algum post.
  • Mude a cor e o tamanho de pelo menos um ícone usando CSS.
